# Contributing

Open an issue before a large change. Keep the single-administrator, campaign-owned recipient and global-suppression boundaries intact. Use synthetic `example.test` data only. Run the full test, static-analysis, migration, license and sanitization gates before a pull request. Do not submit credentials, recipient data, private operations notes or production-derived fixtures. Contributions to first-party code are submitted under AGPL-3.0-or-later; third-party material must retain its license and required notices.
